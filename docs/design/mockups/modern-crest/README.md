# Propuesta visual: insignias y competición

Abrir `index.html` para ver la vista previa interactiva. El selector lateral cambia entre Premier League, Bundesliga, VriendenLoterij Eredivisie, LaLiga, Ligue 1 y Serie A; cada vista actualiza la marca de la competición, los escudos, la clasificación y los próximos cruces.

Las posiciones y los marcadores son datos de muestra para el diseño, no resultados actuales. Las insignias se cargan desde URLs públicas y necesitan conexión a internet.

## Fuentes y uso

- Football-data.org publica emblemas de competiciones y escudos de clubes en sus recursos de competición y equipos: https://docs.football-data.org/general/v4/competition.html
- Logo de la VriendenLoterij Eredivisie: https://eredivisie.nl/meer/merk/logo/
- La página oficial de Eredivisie limita el uso del logo a fines editoriales y pide autorización para uso comercial. Revisar permisos antes de distribuir o publicar la aplicación.

Si una imagen externa deja de estar disponible, la vista la marca como pendiente; no fabrica ni presenta una insignia ficticia como si fuera real.
